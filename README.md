# NLP course labs

Coding part of the laboratory practices I did for the two Natural Language Processing courses of the degree in Mathematical Engineering and Artificial Intelligence at Universidad Pontificia Comillas ICAI (third year).

Author: Pablo Tuñón Laguna.

## Contents

NLP I (spring 2025), in `nlp-1/`:

| Folder | Lab |
| --- | --- |
| `bigram-language-model` | Character-level bigram language model for name generation |
| `naive-bayes-and-logistic-regression` | Bag-of-words sentiment classifiers: Naive Bayes and logistic regression |
| `skip-gram` | Skip-gram with negative sampling |

NLP II (autumn 2025), in `nlp-2/`:

| Folder | Lab |
| --- | --- |
| `transformer-encoder` | Transformer encoder with a sequence classification head |
| `transformer-decoder` | Decoder-only character-level transformer that generates names |
| `transformer` | Encoder-decoder transformer with several decoding strategies |
| `fine-tuning` | LoRA and soft prompt modules |

Each folder has its own README with what was implemented.

## What is and is not included

The labs started from skeletons provided by the teaching staff. Only the source modules are here, with the skeleton documentation and comments removed. The assignment statements, test suites, runner scripts, notebooks and datasets belong to the course and are not included. There is no licence file for that reason: the assignment scaffolding belongs to the course.
